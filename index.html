Native where it matters.

Feather is written in Rust and built with GTK 4 and GtkSourceView 5. It uses your desktop's native toolkit instead of shipping an embedded browser runtime.

01EASIEST

ZIP installer

Download the archive, extract it and run the included installer.

unzip Feather-*-linux-x86_64.zip
cd Feather-*-linux-x86_64
./install.sh
02PORTABLE

AppImage

Make the downloaded AppImage executable and launch it.

chmod +x Feather-*-x86_64.AppImage
./Feather-*-x86_64.AppImage
03FROM SOURCE

Build with Cargo

Install GTK 4, GtkSourceView 5 and the Rust toolchain first.

cargo build --release --locked
cargo run --release

The ZIP installer requires GTK 4 and GtkSourceView 5. The AppImage is more self-contained; compatibility can vary by distribution. See the README ↗ for details.
