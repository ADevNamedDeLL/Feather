# Feather 0.6.0

## Editor essentials

- Added a searchable Command Palette with editor and file commands.
- Added Quick Open for workspace files and recent documents.
- Added Find Next, Replace and Replace All for the active document.
- Added Go to Line navigation.
- Added current-line duplication and line movement.
- Added line comment and uncomment support for common programming languages.
- Added active-document editor settings for line numbers, current-line highlighting, automatic indentation, tab insertion and tab width.
- Added persistent recent-file history, capped at 20 entries.
- Added keyboard shortcuts and updated the help panel and README.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Ctrl+Shift+P | Command Palette |
| Ctrl+P | Quick Open |
| Ctrl+H | Find & Replace |
| Ctrl+G | Go to Line |
| Ctrl+Shift+D | Duplicate Line |
| Alt+Shift+Up / Down | Move Line Up / Down |
| Ctrl+/ | Comment / Uncomment |
